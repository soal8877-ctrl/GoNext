# MVP-SCOPE.md  
## Объём первой поставки GoNext (этап 0, PLAN.md)

Документ фиксирует границы MVP до реализации SQLite и бизнес-логики. Источник требований: [PROJECT.md](./PROJECT.md).

---

## Входит в MVP

| Область | Содержание |
|--------|------------|
| Главное меню | Заголовок GoNext, переходы во все режимы |
| Места | Справочник Place: CRUD, карта, фото (позже) |
| Поездки | Trip + маршрут TripPlace, текущая поездка |
| Следующее место | Первое невизитированное в текущей поездке, карта/навигатор |
| Выражения | 10 фиксированных пар EN/RU, только просмотр, офлайн |
| Настройки | Минимальный экран: о приложении, данные на устройстве (без облака) |
| Данные | Локальный SQLite, офлайн-режим |
| Платформа | Android и iOS через Expo; UI — React Native Paper |

---

## Не входит в MVP (отложено)

- Экспорт поездки в PDF  
- Резервное копирование  
- Синхронизация между устройствами  
- Совместные поездки  
- Статистика путешествий  
- Отображение всего маршрута на одной карте  
- Регистрация, сервер, аккаунты
